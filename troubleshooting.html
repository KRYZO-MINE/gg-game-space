GG Game Space troubleshooting

These are common problems people run into with in-game tool apps, with safe steps to try in order. Work through one at a time and change a setting back if it does not help. The steps explain why each one might work, so you can decide which apply to you.

1. The in-game panel does not appear

  1. Confirm the game was launched from GG Game Space. A panel needs the app to be running alongside the game; launching the game directly may skip it.
  2. Check the "display over other apps" permission. If your device or app version requires it, the panel cannot draw on top of the game without it. Grant it from the app's own prompt. Why it helps: Android blocks overlays unless this permission is given.
  3. Check the app is still running in the background. Open recent apps and confirm GG Game Space was not closed. Why it helps: if the app is stopped, nothing is left to draw the panel.
  4. Restart the game and the app. Close both fully, then launch the game from GG Game Space again.

If the panel still does not appear, see battery restrictions below, then contact support with your device details.

2. Permission or setup prompt problems

  1. Read each prompt before accepting. Grant a permission only when the app explains why it needs it.
  2. Grant one at a time, then retest. This makes it clear which setting actually fixed or caused the issue.
  3. For USB debugging, be careful. It is a developer setting that lets a connected computer control parts of your device. Enable it only if the app's official instructions require it, never authorise an untrusted computer, and switch it off when you are done. Why it may be asked for: some game tools use it during first-time setup.

See the setup guide for what each setting is for. If a prompt is unclear, ask support rather than guessing.

3. Battery restrictions and background operation

  1. Set battery usage for GG Game Space to unrestricted. On many devices: Settings → Apps → GG Game Space → Battery, then choose unrestricted or "no restrictions". Why it helps: aggressive battery management can pause the app in the background and interrupt the panel.
  2. Turn off "remove permissions if app is unused" for the app if your device offers it. Why it helps: this can silently revoke the overlay permission.
  3. Test again without changing anything else. This confirms whether battery management was the cause.

Menu names differ between manufacturers. If you cannot find these options, tell support your device model.

4. The panel opens but closes or stops responding

  1. Update the app. Install the latest version from the Google Play listing.
  2. Close other overlay or recording apps. Two overlays competing for the same screen space can interfere with each other.
  3. Restart your device. This clears a stuck state that a reinstall will not always fix.
  4. Reinstall only as a last step. You may lose in-app settings; note them down first.

5. A tool works in one game but not another

This is usually expected: games control what can run over them and what inputs they accept. A tool shown in the app is not guaranteed to work in every game.

  • Check the game's own rules about overlays, control mapping and automation before using a tool.
  • Some games close or refuse to run with overlays active — that is a decision made by the game.
  • Performance tools (FPS, resolution) depend on your hardware and the game's limits, so results differ by title.

See compatibility for what is and is not verified.

6. Android version or device-specific issues

GG Game Space requires Android 11 or later according to the developer. If you are below that, the app may not install or behave correctly. If you are on a supported version and a problem persists, it may be a manufacturer-specific behaviour.

When to contact support

Contact GG Game Space support if:

  • You have worked through the relevant section above and the problem continues.
  • A permission request looks unusual or you are unsure whether to grant it.
  • The app asks for a device setting you cannot find.

Include your phone model, Android version, app version, the game you tested and what happened. Those details let support give you a specific answer instead of guesses.

Last reviewed: 25 October 2026. Steps are general troubleshooting guidance for in-game overlay tools and should be treated as suggestions, not guaranteed fixes. If a step does not apply to your device, skip it.
