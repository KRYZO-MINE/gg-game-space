GG Game Space compatibility and requirements

Check these requirements before installing. Device makers customize Android, and game publishers can limit overlays or automation tools, so individual features may behave differently even on compatible devices.

Platform
Android
Minimum Android version
Android 11 or later, based on the product information supplied for this website. Always check the current Google Play listing for device-specific availability.
Root
Root is not required. The product owner also reports use on rooted devices; this does not guarantee every feature will work on every rooted setup.
Battery and debugging setup
Some setup instructions may ask for unrestricted battery use or USB debugging. See the setup guide and enable sensitive settings only when official instructions require them.
Supported games
No verified, complete supported-games list is published here. Check the app and each game's rules before relying on a feature.

Why compatibility can vary

Android version, device manufacturer settings, screen layout, game updates, and game policy can all affect an in-game panel and its tools. A tool shown in screenshots is not a promise that it works in every game. FPS, resolution, memory, and other performance-related results depend on hardware and software and are not guaranteed.

For setup help, read Getting Started or contact GG Game Space support.
