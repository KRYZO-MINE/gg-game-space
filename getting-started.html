How to set up GG Game Space

This guide covers the basic path shown by the app: install GG Game Space, add a game, open the game, and use the tools from the in-game panel. Button names and setup prompts can change between app versions and Android devices, so treat this as the shape of the flow rather than an exact click-by-click script.

Before you start

  • Device: an Android phone or tablet running Android 11 or later (developer-stated).
  • Source: install only from the official Google Play listing.
  • A game to test with: start with one game whose rules allow overlays and control tools, so you can experiment safely.
  • A few minutes of setup: some devices ask for extra settings the first time you use an in-game panel.

1. Check your Android version

Open Settings → About phone → Android version and confirm you are on Android 11 or later. The compatibility page explains the current requirements and what is not yet verified.

2. Install from Google Play

Use the official Google Play download page. Confirm the app name and listing before installing, and avoid third-party APK mirrors or links shared by unknown accounts.

3. Add a game in the app

Open GG Game Space and use its Added Games list to choose a game. Add the game you want to use tools with; the app keeps this list so you can launch from it.

4. Open the game and the tool panel

Launch the game from GG Game Space as the current version instructs. With the game running, open the GG Game Space panel to see the available tools, such as keymap, macro, virtual crosshair, resolution and device information. The panel and feature set can vary by game and device.

5. Understand the permissions and settings the app may request

Some steps below are device settings rather than app permissions. Enable them only when the app's official instructions require them, and change them back when you are done.

Settings GG Game Space and similar overlay tools may involve
SettingWhat it is forStatus
Display over other apps (overlay) Lets an app draw on top of other apps. An in-game panel needs a way to appear over a running game. Confirm in-app whether your version asks for it and grant it only from the app's own prompt.
Battery usage: unrestricted / no restrictions Stops Android from aggressively pausing the app in the background, which can otherwise interrupt the panel during a session. Developer-stated the app advises unrestricted battery use for some setups.
USB debugging (Developer options) Used by some game tools during first-time setup or advanced configuration. Sensitive developer-stated setup mentions it for some setups. Turn it off when you no longer need it.
Root access Not required. Not needed Root is not required; the developer states the app also works on rooted devices.

Safety notes: USB debugging lets a connected computer control parts of your device. Enable it only if the app's official instructions require it, never authorise an untrusted computer, and switch it back off afterwards. If a permission prompt is unclear, stop and ask support before granting it.

6. If something does not work

If the panel does not appear, a game closes unexpectedly, or a permission seems to block setup, work through the troubleshooting guide. It covers the most common setup problems and when to contact support.

Last reviewed: 25 October 2026. Setup steps can change with app and Android updates; this page describes the flow shown by the app and the information provided by its developer.
